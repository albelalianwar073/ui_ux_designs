# قائمة إنجاز مشروع دمك حياة

## الصفحات والبنية

- [ ] تنفيذ الصفحات الثماني كاملة بالعربية مع `lang="ar"` و`dir="rtl"`، وربطها بروابط نسبية.
- [ ] إنشاء `css/style.css` خارجي وربطه بكل صفحة، وإنشاء `js/main.js` و`js/team.js` و`js/form.js`.
- [ ] إنشاء مجلدي `images` و`videos` وتخزين الأصول البصرية محلياً.
- [ ] توفير `manus-routes.json` بالمسارات الثابتة الثمانية.

## الرئيسية

- [ ] Hero بعرض كامل وصورة خلفية وoverlay والشعار وزرا «ابحث عن مستشفى» و«سجّل كمتبرع».
- [ ] عدادات متحركة للمتبرعين والمستشفيات والأرواح المستفيدة.
- [ ] خطوات العمل بأيقونات، بطاقات مستشفيات مميزة، شريط احتياج عاجل، واقتباس وتذييل.

## المستشفيات

- [ ] بحث نصي وفلاتر مدينة وفصيلة دم تعمل مباشرة عبر JavaScript.
- [ ] عرض 12 منشأة حقيقية على الأقل في المدن السعودية المطلوبة مع ساعات بنك الدم ورابط خرائط.
- [ ] جدول مقارنة للمستشفيات والخدمات وساعات التبرع، مع تمرير أفقي على الشاشات الصغيرة.

## التسجيل والتثقيف

- [ ] نموذج تبرع متعدد المدخلات: text/email/tel/number/date/password/select/radio/checkbox/textarea وأزرار submit/reset.
- [ ] إضافة placeholder وpattern وtitle وrequired وmin/max وminlength/maxlength حيث يلزم.
- [ ] رسائل تحقق عربية تحت كل حقل، regex للبريد والجوال والهوية والاسم، وحالة نجاح ورسالة/modal عند صحة النموذج.
- [ ] قوائم شروط الأهلية وخطوات قبل وأثناء وبعد التبرع وخط زمني للعملية.
- [ ] عرض فصائل الدم الثماني، جدول التوافق، اختيار تفاعلي للفصيلة ومعلومات الندرة.
- [ ] أقسام فوائد التبرع والأساطير والحقائق والنصائح وFAQ وفيديو توعوي مع وصف.

## المعرض والفريق والتواصل

- [ ] معرض responsive بصور محلية وalt عربي وتصنيف للحملات والمستشفيات والتوعية.
- [ ] hover zoom وcaption overlay وlightbox مع التالي والسابق والإغلاق.
- [ ] قائمة `ul/li` لأربعة أو خمسة أعضاء، وترتيب Fisher–Yates عشوائي عند كل تحديث عبر `team.js`.
- [ ] تعليقات HTML واضحة لمواضع تعديل أسماء وأرقام أعضاء الفريق.
- [ ] نموذج تواصل، بيانات اتصال، iframe لخريطة، جدول ساعات، روابط اجتماعية وFAQ.

## التصميم والتفاعل

- [ ] Header ثابت/ملتصق مع شعار وروابط الصفحات وزر «تبرع الآن» ورابط نشط.
- [ ] Hamburger متحرك للهاتف، ظل وتصغير header بعد التمرير، زر عودة للأعلى وشريط تقدم التمرير.
- [ ] IntersectionObserver وعدادات وhover lift وripple/pulse وaccordion وlightbox وحركة تحميل و`prefers-reduced-motion`.
- [ ] استخدام CSS variables وflexbox وgrid وgradients وshadows وtransforms وkeyframes وpseudo-elements وmedia queries وobject-fit وoverflow وtext-shadow وغيرها.
- [ ] إضافة style داخلي في 3 صفحات على الأقل وinline style في 5 مواضع على الأقل، مع classes وIDs متعددة.
- [ ] التحقق من mobile/tablet/desktop وعدم وجود overflow أو أخطاء JavaScript أو روابط مكسورة.

## التسليم

- [ ] مراجعة مصدر الصفحات والروابط والنماذج والبنية والأصول.
- [ ] إنشاء ZIP كامل بالبنية المطلوبة.
- [ ] حفظ checkpoint والنشر إلى رابط مجاني بعد نجاح التحقق.
- [ ] تسليم checklist نهائي يؤكد المتطلبات المنفذة.
